# Project Genesis — Research Questions

This is not a feature list or a TODO file. It is a record of unanswered scientific questions that should guide experiments, controls, and interpretation as Project Genesis grows.

## Structural evolution

- Is Prime 31 structural coupling an evolutionarily stable strategy, or only temporarily useful under favorable conditions?
- Under what ecological conditions can bonds and facets persist across many generations rather than appearing as transient blooms?
- Does topology-aware structural inheritance improve long-term structural lineage persistence?
- What operating margin is required for a three-body facet to pay its maintenance cost and continue solving tasks?
- Can non-structural lineages invade a mature structure-producing ecosystem, and can the structures resist that invasion without a hidden private reward?

## Distributed computation

- Does distributed state across bonds outperform individual persistent state for any measurable ecological task?
- Can facets evolve more reliable consensus behavior as gate tasks, environments, and seed blocks vary?
- Can communication evolve usable semantics rather than remaining undifferentiated signal activity?
- When does scarce, non-local information improve collective work, and when does it create destabilizing coordination noise?
- Can a new computational primitive invade an already established ecosystem instead of merely helping a seeded population bootstrap?

## Ecological engineering

- Can task-producing facets create stable niches rather than short-lived public resource pulses?
- What balance of public access and worker-local access permits both competition and sustained collective work?
- Can ecological engineering create stable productive regions, migration corridors, or succession patterns visible in long-run spatial history?
- Does the high-output port-coupled gate regime remain structurally persistent at 1,000 and 2,000 ticks?
- Are productive facet regions reproducible across independent seeds, or dependent on contingent map and founder placement?

## Environmental memory — Phase 16

- Does neutral environmental memory become selected when read and write capabilities arise only through mutation?
- Do Prime 41 and Prime 43 persist together more reliably than either write-only or read-only capability?
- Can evolution discover a useful interpretation of a persistent scalar without it being defined as food, danger, home, trail, or signal?
- Does environmental computation complement individual and distributed structural computation, or is it redundant in the current ecology?
- Can memory-mediated strategies remain beneficial under invasion by lineages that do not pay write costs?

## Methodology and interpretation

- Which apparent successes survive fresh seed blocks, longer horizons, and matched negative controls?
- Which observed patterns are true selection effects rather than transient dynamics, visual salience, or parameter tuning?
- What minimal telemetry is required to distinguish worker benefit, free-riding, lineage persistence, and accidental correlation?
- Which new primitives are scientifically justified by a specific unanswered question, rather than by novelty alone?

New work should state which question it tests before it adds a primitive, changes an ecological rule, or claims an emergent result.
